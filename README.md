# Privacy policy – Twitch Follow Sort

Public privacy policy for the browser extension **Twitch Follow Sort**.

The policy itself is `index.html` and is published via GitHub Pages:

```
https://enziaga.github.io/twitch-follow-sort-privacy/
```

It covers the extension in both Chrome and Firefox and is written in English and German on one page.

## Contents

- What the extension handles (channel names from the followed-channels list, local settings)
- Why (sorting the channel list only)
- Where the data stays (locally via `chrome.storage.local`, no servers)
- Export and import (local JSON file, user-controlled)
- Permissions (`storage`, `https://www.twitch.tv/*`)
- Retention and deletion
- Contact

## Updating

Edit `index.html`, bump the date at the top, commit and push. GitHub Pages publishes the change within a minute or two.

The same file is kept in the extension repository under `store/privacy-policy.html`.
